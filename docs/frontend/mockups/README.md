# Redesign mockups

Static HTML mockups for the redesign described in `../redesign-spec.md`. Open a file
in a browser. They use sample data and load fonts and icons from a CDN.

| File | What it is |
|---|---|
| `pages.html` | **The reference.** Real pages in the chosen style, second pass. |
| `layout-iterations.html` | Four overview layouts; layout 1 (top bar) was chosen. |
| `glass-accents.html` | Earlier glass samples in five accent colours; amber was kept. |
| `first-directions.html` | The first three directions (Ledger, Liquid glass, Blocks). |

Where a mockup and the spec disagree, the spec wins.
